# GitHub Project Ledger

This repository has an external GitHub Project used to track the NZ full-country
coverage roadmap and the completed implementation history from the downstream
fork.

Project:

- https://github.com/users/edithatogo/projects/1

The project contains the downstream issue ledger for work completed since the
fork:

- `#27` through `#45` record completed Conductor implementation tracks.
- `#46` is the open umbrella roadmap issue for full-country NZ legislative and
  social policy coverage.
- `#41` links the OpenFisca follow-on reconciliation track to merged PR `#26`.

Canonical local roadmap inputs:

- `data/coverage/full-country-backlog.json`
- downstream Conductor track registry and archived track plans

This file is documentation only. The GitHub Project itself is account metadata
and cannot be represented directly in a repository pull request.
